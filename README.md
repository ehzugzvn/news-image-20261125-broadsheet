# The World in One Day — Broadsheet

A classic cream broadsheet summing up Wednesday 25 November 2026 in one
image: 38 stories from 7 regions, every one dated to that Wednesday, with a
giant masthead date, a day-in-numbers strip, four illustrated leads, ten
tier-2 stories with pictograms, a numbered world map, 24 large-type briefs,
a UTC timeline and a date-check strip.

## How it works

`render.py` (PIL) draws `entry.png` (1024×1024) — every illustration is
drawn with PIL shapes, no external images. `main.py` (Python 3.13, standard
library only) copies `entry.png` to `MAKEFUN_OUTPUT_DIR` (or `/output`),
byte-identical every run.
